# GitHub build and upgrade safety — WQA365 existing sandbox

1. **Use the same GitHub repository/workflow that built the owner-tested v0.1.7 sandbox.** Extract this ZIP first. Upload/commit the extracted source tree (`app/`, `tests/`, `build.gradle`, `settings.gradle`, etc.) so `app/build.gradle` resides at repository-root `app/build.gradle`. Simply uploading the ZIP alone does not make GitHub Actions compile it. Preserve any repository's existing `.github/workflows/` and any existing signing-key configuration.
2. Build with JDK 17, Gradle 7.5, Android Gradle Plugin 7.4.2, Android SDK platform 33. Use the previously working workflow, or its conventional `gradle :app:assembleDebug` step. The ZIP intentionally carries **no** fake keystore, no debug key and no new workflow that might change the signing identity. A source-only candidate can still fail Android compilation.
3. Inspect the APK **before installing**. `aapt dump badging app-debug.apk` should report package `org.roarin.kyocerakeypad.sandboxwqa365` and versionCode `7`. If that ID is not exact, do not install. `apksigner verify --print-certs app-debug.apk` reveals the built APK's signing fingerprint; compare to the owner-tested installed sandbox APK fingerprint. The earlier CI debug keystore may not have persisted, in which case APK replacement will fail.
4. Install using the ordinary Android APK installer or `adb install -r path/to/app-debug.apk`. Android updates the existing sandbox **only if package ID, signing identity and version rules all match**. Do not use `adb uninstall`, `pm clear`, a new app ID, or Android's "uninstall first" option to solve incompatibility; those actions risk the existing private playlist/bookmark/progress data. The original production app has a distinct ID and must remain untouched.
5. Treat this DEV4 as **unverified source** even after a successful compilation. Test only with disposable media and record any foreground-service, screen-sleep, flip-close, call-interruption, and D-pad selection defects. DEV4 did not pass Android runtime testing; there is no claim of an accepted replacement APK.

**Reference identities:** Original player: `org.roarin.kyocerakeypad`; existing v0.1.7 sandbox targeted by this build: `org.roarin.kyocerakeypad.sandboxwqa365`. Previous incorrect DEV4 third-install ID: `org.roarin.kyocerakeypad.sandboxdev3` (must not appear as the new Gradle applicationId).
