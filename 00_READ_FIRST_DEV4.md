# Kyocera Keypad Player DEV4 — source for an IN-PLACE update of the existing WQA365 sandbox

**Not a verified APK. Not a device-trial release.** DEV4 has passed host/static checks only; Android SDK compilation and on-phone lifecycle behavior remain unverified. This archive is an identity-and-documentation revision of the source-only DEV4 build attempt, not a service-lifecycle bug fix.

**Target already installed:** `org.roarin.kyocerakeypad.sandboxwqa365` (owner-tested v0.1.7 sandbox, previously source versionCode 6). DEV4 sets **versionCode 7**, versionName `0.1.8-dev4-wqa365-update-source`, and the same visible launcher label `Keypad Sandbox WQA365`. Java namespace remains `org.roarin.kyocerakeypad`, with its activity/service class paths unchanged. **Do not change applicationId again** or Android will create a third app.

**Critical signing condition:** The resulting APK MUST be signed with the identical certificate/signing lineage used for the installed WQA365 APK. Standard GitHub Actions `assembleDebug` can create a different ephemeral debug keystore on each runner, even in the same repository, and then cannot update the existing app. If Android reports `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, **do not uninstall or clear data**; locate the original signing keystore or use a build method that preserves it. VersionCode 7 must also be higher than the actual installed versionCode. Check actual installed APK if the historical 6 is wrong.

**Build needs:** JDK 17, Gradle 7.5, Android Gradle Plugin 7.4.2, Android SDK platform 33. There is no Gradle wrapper or keystore in this ZIP. Unzip and upload source files (not the ZIP file as a single repository member) to your established GitHub build repository/workflow. `gradle :app:assembleDebug` is the conventional command when Gradle is configured. This creates an APK only if Android compilation succeeds. No GitHub build or phone install occurred here. The `README_GITHUB_WQA365_IN_PLACE_UPDATE.md` contains further checks.

**Open engineering issues:** DEV4 source has provisional changes for foreground service lifecycle, failed starts, audio focus, sleep/flip continuation and D-pad focus preservation. Service-aware source checks don't establish Android callback correctness. An inherited Activity-specific guard is obsolete after the service migration; its original failure remains recorded in the project history. New test guards are structural, not Android runtime tests. Standard Bluetooth media buttons have not been validated on the phone.

**Provenance:** Source is derived from `KYOCERA_KEYPAD_DEV4_BUILD_ATTEMPT_SOURCE_ONLY.zip`; earlier `PROVENANCE_WQA365_SOURCE_MANIFEST_HISTORICAL.json` is historical and does NOT describe DEV4 bytes. `SOURCE_MANIFEST.json` lists actual SHA-256 for all members in this ZIP, excluding that manifest itself. No original app, owner's phone, private music, GitHub repo or existing ZIP was changed.
